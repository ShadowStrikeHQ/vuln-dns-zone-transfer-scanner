# vuln-DNS-Zone-Transfer-Scanner
Detects potential DNS zone transfer vulnerabilities by attempting an AXFR request against a given domain's nameservers. - Focused on Assess vulnerabilities in web applications by performing scans and providing detailed reports

## Install
`git clone https://github.com/ShadowStrikeHQ/vuln-dns-zone-transfer-scanner`

## Usage
`./vuln-dns-zone-transfer-scanner [params]`

## Parameters
- `-h`: Show help message and exit
